# 🚁 Vice City Skydrop

An interactive browser-based drone delivery game set in a neon-inspired
city. Pilot your courier drone, collect priority cargo, and deliver
packages to rooftop drop zones before the mission timer runs out.

## 🎮 Features

-   Control a delivery drone across the city
-   Pick up and deliver cargo to rooftop drop zones
-   Complete delivery missions and build delivery streaks
-   Earn cash for successful deliveries
-   90-second mission countdown
-   Drone condition system with limited impact charges
-   Boost and pause controls
-   Keyboard and mobile touch controls
-   Neon-inspired, responsive game interface

## 🕹️ Controls

  Action                 Control
  ---------------------- ----------------------------------
  Move                   `W`, `A`, `S`, `D` or Arrow Keys
  Pick up / Drop cargo   `Space`
  Boost                  `Shift`
  Pause                  `P`

On supported mobile screens, use the on-screen touch controls.

## 🛠️ Technologies Used

-   HTML5
-   CSS3
-   JavaScript
-   HTML Canvas API

## ▶️ How to Run

1.  Download or clone this repository.
2.  Open the project folder.
3.  Open `index.html` in your web browser.
4.  Start your delivery run and complete the missions.

## 🎯 Objective

Complete five deliveries by collecting cargo and dropping it at the
marked rooftop zones. Manage your time and keep your drone in good
condition to finish the run.
